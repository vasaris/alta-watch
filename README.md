# alta-watch

Бот, который раз в 10 минут проверяет официальные источники и публикует
в Telegram-канал новые сообщения об ALTA banka. Если нового нет, бот молчит.

Источники (только официальные):

- **aod.rs** — новости Агентства по страхованию вкладов, объявления («Огласи»,
  это PDF-файлы) и страница «Поступци у току»: бот один раз сообщит, когда
  там появится ALTA.
- **nbs.rs** — официальный RSS всех новостей Народного банка Сербии.
- **altabanka.rs** — заявления и новости самого банка. Если банк перезапишет
  заявление по тому же адресу, бот опубликует его заново с пометкой «обновлено».

- **Пресса** — RSS проверенных изданий: N1, Danas, Nova ekonomija, Forbes Srbija,
  Nova.rs, агентство Beta, BIZLife. Берутся статьи не старше 48 часов, где Alta
  упомянута в заголовке или лиде. Публикуются не целиком, а одной подборкой
  «📰 Пресса» за запуск (до 10 ссылок), чтобы не засорять канал.

У регуляторов берутся только публикации с упоминанием Alta/Алта (для объявлений
AOD шире: всё про выплаты, вкладчиков и банкротство). С сайта банка — всё.

Принудительно опубликовать конкретные ссылки (например, вышедшие до старта бота):
Actions → alta-watch → Run workflow → поле `force_urls`, ссылки через запятую.
Или из терминала: `gh workflow run alta-watch -f force_urls="url1,url2"`.

Работает на GitHub Actions, сервер не нужен.

## Установка

1. **Бот в Telegram.** Напишите @BotFather → `/newbot` → получите токен вида
   `123456789:AAH...`.
2. **Канал.** Создайте канал, добавьте бота администратором с правом
   «Публиковать сообщения». Для публичного канала ID — это `@имя_канала`.
   Для приватного — числовой ID вида `-100XXXXXXXXXX` (перешлите любой пост
   из канала боту @userinfobot или @getidsbot, он покажет ID).
3. **Репозиторий.** Создайте на GitHub новый репозиторий (можно приватный)
   и загрузите в него содержимое этого архива. Структура должна сохраниться:
   `.github/workflows/watch.yml`, `watch.py`, `requirements.txt`, `state/seen.json`.
4. **Секреты.** В репозитории: Settings → Secrets and variables → Actions →
   New repository secret. Добавьте два:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHAT_ID` — `@имя_канала` или числовой ID из шага 2.
5. **Первый запуск.** Вкладка Actions → `alta-watch` → Run workflow.
   Первый запуск запоминает всё, что уже опубликовано на сайтах, и ничего
   не постит, кроме сообщения «Бот запущен». Дальше работает сам.

## Как это устроено

- `watch.py` собирает ссылки со всех источников, открывает новые, фильтрует
  и публикует заголовок, дату, первые абзацы и ссылку на первоисточник.
  Текст не пересказывается и не переводится: публикуется оригинал.
- `state/seen.json` — список уже просмотренных ссылок. Workflow коммитит его
  обратно в репозиторий после каждого запуска.
- Расписание `*/10 * * * *`. GitHub может задерживать запуски на несколько
  минут, в часы пик и больше. Это нормально.

## Проверка без Telegram

```
DRY_RUN=1 python watch.py
```

Посты печатаются в консоль, в Telegram ничего не уходит.

## Остановить

Actions → `alta-watch` → ⋯ → Disable workflow. Или удалите репозиторий.
Токен бота потом можно отозвать в @BotFather (`/revoke`).
